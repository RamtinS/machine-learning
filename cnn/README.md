# Convolutional Neural Networks (CNN)  

## What is a Convolutional Neural Network?  

Convolutional Neural Networks (CNNs) are a type of deep learning model specialized for image processing tasks. They use convolutional layers to extract spatial features, making them effective for tasks like object recognition and classification.  

## Task Description  

This project involves training and extending CNN models for image classification using MNIST and Fashion MNIST datasets.
